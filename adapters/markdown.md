# markdown

이력서 원본이 마크다운 파일인 경우입니다. 기본 형식입니다.

## 편집

- 편집 직전에 파일을 다시 읽습니다. 사용자가 편집기에서 고쳤을 수 있습니다.
- 바꿀 문장만 바꿉니다. 파일 전체를 다시 쓰지 않습니다.
- 저장소로 관리하면 큰 변경 전에 커밋을 남깁니다. 아니면 `<home>/versions/`에 날짜를 붙인 사본을 둡니다.

## 구조 관례

```markdown
# 이름
헤드라인 · 이메일 · 전화 · 링크

## 핵심 역량
- **결과 리드**: 본문

## 프로젝트 · 회사명
### 프로젝트 이름 (2025.12 – 현재)
소개 한 단락
서비스 주소 · App Store · Google Play

**소제목**
- **결과 리드**: 본문
```

## 렌더

마크다운을 PDF로 바꾸는 도구는 사용자가 정합니다. 예를 들어 pandoc, 문서 편집기의 내보내기, 정적 사이트 생성기가 있습니다.
쓰는 방법을 workspace의 `render`에 적습니다.

node scripts/check-copy.mjs <home>/resume.md
